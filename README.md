# Previsão de Demanda no Varejo

Projeto desenvolvido como Trabalho de Conclusão de Curso em Engenharia da Computação.

## Objetivo

Construir um pipeline completo de Engenharia de Dados utilizando PostgreSQL, Python e Machine Learning para previsão de demanda em dados do Brazilian E-Commerce Dataset by Olist.

## Tecnologias

- PostgreSQL
- Python
- Pandas
- SQLAlchemy
- Scikit-learn
- Power BI
